# Suvam Birthday Website

A single-file, mobile-first birthday website for Suvam ("Chinar"), originally supplied as an HTML concept and upgraded with a more realistic cinematic starfield.

## What's included

- Restricted-access intro gate
- Civil-engineering / blueprint-inspired visual style
- Animated hero section
- Then-vs-now friendship assessment
- Friendship revision timeline
- Embedded photo gallery
- Interactive birthday candle + confetti
- Responsive mobile layout
- Reduced-motion support
- **Upgraded realistic starfield**
  - layered star depths
  - soft atmospheric halos
  - varied star temperatures
  - subtle Milky Way haze
  - realistic bright-star diffraction spikes
  - restrained floating particles
  - occasional shooting stars

## Files

- `index.html` — complete website. No build system or dependencies required.

## Run locally

Open `index.html` in a browser.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`.
3. Go to **Settings → Pages**.
4. Set the source to the `main` branch and `/ (root)`.
5. Save and open the generated GitHub Pages URL.

The page is intentionally self-contained, so the embedded photos and website logic do not require an asset folder.

## Important

The original page content and interactions were preserved; the main visual change is the starfield rendering.
